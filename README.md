## 🔬 Featured Project Highlights

### 1. In-Memory Virtual File System

A thread-safe and persistent virtual file system implemented from scratch in C++17.

- Composite Design Pattern for files and directories.
- N-ary tree-based hierarchical structure.
- `std::shared_mutex` for reader-writer synchronization.
- Custom binary serialization for persistence and state reconstruction.
- Concurrent file-system operations and recursive resource management.

**Tech:** C++17 · Data Structures · Concurrency · Binary Serialization

[Repository →](https://github.com/siddharthh-29/In-Memory-VFS)

### 2. GNSS-Based Intelligent Road Tolling System

**Winner — Smart India Hackathon 2024 Finals | ISRO Problem Statement**

An intelligent map-matching solution to distinguish vehicles travelling on highways, service roads, and flyovers using coarse GNSS data.

- Kalman filtering and Z-score-based outlier detection.
- OSRM-based road snapping and map matching.
- Switching Hidden Markov Model for road-state classification.
- Simple and complex model configurations using vehicle features.
- Flask application for trajectory visualization and toll analytics.

**Tech:** Python · Flask · HMM · Kalman Filters · OSRM · OpenStreetMap

[Repository →](https://github.com/siddharthh-29/SmartIndiaHackathon)

### 3. SpatialMesh — Immersive 3D Spatial Audio

**Samsung EnnovateX AX Hackathon 2026 | Problem Statement 8**

An AI-powered spatial audio system that transforms multi-party voice calls into immersive 3D listening experiences.

- Four-layer 1D CNN for audio feature extraction.
- Graph-based speaker representation with 133-dimensional nodes and seven-dimensional directed edges.
- GATv2 Graph Neural Network for joint azimuth and elevation prediction.
- HRTF-based binaural audio rendering using SONICOM.
- Rule-based Spatial Context Agent for context-aware soundfield adjustments.

**Reported KPIs:**

- GNN inference latency: 0.63 ms
- Model size: 4.81 MB
- Spatial separability: 96/100
- Concurrent speakers: 4

*Reported project KPI results; GNN inference time is not the same as end-to-end audio latency.*

**Tech:** PyTorch · PyTorch Geometric · GATv2 · CNN · Librosa · SciPy · SONICOM · MediaPipe · Gradio

[Repository →](https://github.com/Rohith-0605/SpatialMesh-AX2026) · [Demo](https://youtu.be/VT_2EgvCe5k) · [Presentation](https://drive.google.com/file/d/1mayaPPAfyEff-Vt1P6nm2eUfwn0psPMj/view?usp=sharing)
